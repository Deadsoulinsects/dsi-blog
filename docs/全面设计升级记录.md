## 过程与取舍

### 历史基线和共同视觉基础

### 导航行为的后续确认

早期参考方案及 Phase 1 报告采用无人工等待的导航目标；后续确认并保留的生产行为是：

- 精确当前路由点击不刷新；
- 同栏目嵌套路由到栏目根立即导航；
- 普通跨栏目使用单一同 DOM slider，200ms 后进入目标页；
- reduced-motion 立即导航；
- 浏览器原生修饰键与中键语义保留。

因此，不能为了执行旧 roadmap 的“移除等待”再次撤回当前已确认行为。Docs 与 Categories 的后续报告验证了普通跨栏目 200ms 和 reduced-motion 立即导航。
