# DSI Admin 更新记录

更新记录描述具体版本变化，不代替开发日志或验收证据。源码与包版本应一致；未完成验收的条目不视为正式发布。

## 未发布：2026-10-12（专题置顶与自动补位）

- 文章页专题区改为最多两项：用户置顶的一级专题优先，第二项按专题内最新文章完成日期（含后代）补位，排除重复；无有效置顶时按最近顺序补满，专题不足不造空位。
- 不再按写死的专题名查找，避免改名或专题缺失导致展示空缺。原有专题描述、文章归属和路由保留。
- Admin 的“编辑描述 / 置顶”支持一级专题置顶、替换和取消；只保存本地草稿，确认差异后可单独或随文章提交 `src/data/topics.json`。
- 描述与置顶共用版本、冲突和过期确认保护，不新增文章准备任务。父子描述独立，子专题不作为文章页置顶项。
- 本轮仅更新源码和文档，未重建安装包、未修改真实安装 data，未提交或发布正式仓库。

## 未发布：2026-10-12（原笔记选择与显式迁移）

- 原始 Obsidian 笔记留在自然目录，通过 Admin 选择公开，不再新增“博客发布”副本；默认目录与待确认扫描排除“博客发布”和 `picture`，来源目录与网站专题可分别维护。
- 已有文章需明确重新绑定原笔记，保留目标文件名、URL、`mediaId` 和其他技术字段。旧绑定继续工作，不自动替换来源路径。
- 原笔记候选按文件名或标题匹配，忽略大小写、Unicode 表示与空白差异，排除历史发布副本；唯一候选也不自动绑定。后端拒绝可能重名或同标题的新导入，提示显式绑定。
- 原笔记和旧副本可能各有修改，由作者先比较并选择原笔记内容；迁移不覆盖私人笔记、不删除副本。
- 根目录 `prebuild` 移除 `sync:blog`，保留 `sync:origin` 与其他准备步骤。手动同步须明确传入 `--file`，支持 `--dry-run`；不传文件只输出说明，不扫描历史默认目录或写入。
- 本次仅更新源码，未重建安装包、未修改已安装数据。安装版使用新流程需后续打包升级，本文不代表包内验收已完成。

## 未发布 — 2026-10-12（批量准备与专题描述）

- Admin 可按完整专题路径编辑父专题与子专题描述；本地草稿持久保存，确认差异后单独或随文章提交 `src/data/topics.json`，不自动推送。
- 保留原有两项专题描述、精选专题与路由；清空字段移除页面介绍。专题描述变化不触发文章准备，外部修改或旧版本差异不能被覆盖。
- 多篇文章在一个隔离工程中统一准备，静态检查和构建各执行一次，不再按篇重复复制工程与启动全站验证。
- 同批相同附件及后续批次复用派生资源；原文同步发现的多篇变化合并为一批准备。
- 保留逐篇问题、取消和版本替代保护；整批检查失败时不把待验证文章标为就绪。
- 就绪文章打开或重读提交差异时复用当前检查结果，不再新增准备任务或重复执行 Astro 检查和构建；原文、附件、草稿或工程变化后仍须重新准备。
- 在准备阶段完成网页派生资源的实际构建验证；提交差异保留版本、链接闭包、资源完整性和合并媒体预算检查。
- 隔离准备与发布验证的 Astro 缓存，避免与开发预览共用内容缓存。
- 本次仅更新源码；未生成新安装包。

- 增加无 frontmatter 草稿序列化和旧工作区重启迁移回归。

## 0.1.2 — 2026-10-10（本地交付，未发布 GitHub）

- 博客与 Admin 日期统一使用 `completion_date`，界面显示“完成日期”；旧 `pubDate` 在缺少新字段时迁移，明确的空日期不回退。
- 移除新文章默认当天或文件修改时间的日期推导，缺失、无效完成日期会阻止准备就绪。
- 源笔记同步标题、描述、专题、标签和日期，保留站点技术字段与其他自有元信息；支持旧工作区日期迁移。
- 导入时移除 `article-header-sync` 的完整受管头部，避免标题、描述和日期重复；异常标记提示修正，原笔记不改写。
- 保留可选起止日期与标签，并校验对应字段。Docs 日期规则不变。

## 0.1.1 — 2026-10-03（本地交付，未发布 GitHub）

### 修复

- 保留安装后 Astro check/build 真正需要的生产依赖声明文件，修复 `templates/content/types.d.ts` 缺失导致的 ENOENT。
- 相同文章的运行版本复用已有准备任务；连续修改合并到最新待处理版本，旧版本不再被记为当前文章失败。
- 批量导入合并为批量准备记录，而不是每篇创建一个不明含义的独立记录。
- 新错误去除终端颜色控制符；旧日志仍能展开查看。

### 使用体验

- 安装目录页提前说明 data 位置和仓库／笔记库隔离要求；配置错误列出冲突目录。
- 导入目录默认折叠，整目录勾选无需展开。
- 专题树与文章列表在上方，当前文章全宽编辑与预览在下方，减少双栏空间浪费。
- 功能板块可展开折叠，状态刷新保留用户选择。
- 任务显示文章、触发原因、时间、阶段与逐篇结果，原始技术信息折叠。
- 增加站点专题／文章路径结构检查。
- 补齐产品介绍、使用与开发 README、版本记录，并同步维护。

### 升级与验收

沿用安装目录 data，升级不迁移正文来源、不自动提交或推送。更新前建议备份 data。

包内真实准备、同版本复用与最新修订合并、实际 DSI-blog 工程检查已经通过，正式文件及 HEAD 不变。Windows 安装提示、原生桥、自动保存和任务取消也已验证。最终界面 L2 验收覆盖七个宽度、84 篇文章、144 篇目录笔记及旧任务兼容，详见 [验收记录](./验收记录.md)。
